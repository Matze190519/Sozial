## Editieren

- **Folien löschen / sortieren / neue dazwischen einfügen** → in beiden Varianten möglich.
- **Texte ändern** → in der **Text-Variante** direkt; in der Bild-Variante über Textboxen drüberlegen oder Folie ersetzen.
- **Originaltext jeder Folie** steht in den **Notizen** (Ansicht → Notizen) – einfach copy-paste in eigene Folien.
